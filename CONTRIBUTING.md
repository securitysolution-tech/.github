# Contributing

These repositories are maintained by the SecuritySolution.tech team. If you are working
in one of them, the working agreement is the company handbook
(`securitysolution-tech/handbook`, start at its `AGENTS.md`). In short:

- Verify before you commit: run the repository's gates (check, build, test, audit, format).
- Commit with the company's identity. No AI attribution lines anywhere.
- Never commit a secret. Credentials are short-lived and come from the owner.
- A push to `main` on the website deploys live, so push only when asked.

Security issues go to the [security policy](SECURITY.md), not to a public issue.
